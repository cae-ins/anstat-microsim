# Action requise avant diffusion publique

Aucune licence générale ne doit être inventée pour ce dépôt. Avant l’archivage public, les auteurs ou l’ANStat doivent :

1. choisir et approuver une licence pour le code (par exemple une licence libre compatible avec la politique institutionnelle);
2. confirmer que les fichiers de paramètres et de concordance construits par le projet peuvent être redistribués sous cette licence;
3. conserver les microdonnées EHCVM, TRE et matrices tierces sous leurs conditions propres;
4. ajouter un fichier `LICENSE` à la racine et renseigner la colonne `licence` du manifeste;
5. fournir une déclaration de disponibilité des données cohérente avec ces choix.

Tant que cette décision juridique n’est pas prise, le paquet est techniquement reproductible localement mais pas prêt à être archivé comme paquet public complet.
