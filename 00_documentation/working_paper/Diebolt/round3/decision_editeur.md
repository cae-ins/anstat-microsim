# Décision éditoriale — troisième tour

**Verdict : révisions mineures**

Les cinq rapports convergent. Le manuscrit est publiable comme document de travail ANStat et se rapproche d'une version soumissible à une revue d'économie du développement ou de finances publiques. Aucun rapporteur ne demande de réécriture générale.

## Changements exigés pour clore le tour

1. Réduire le résumé sous 150 mots. **Fait : 143 mots.**
2. Centrer l'introduction sur la tension inégalité--pauvreté. **Fait.**
3. Supprimer la collision de notation R dans l'IGR. **Fait.**
4. Neutraliser les titres promotionnels et les formulations techniques. **Fait.**
5. Appliquer les corrections bibliographiques déjà vérifiées. **Fait : onze notices.**
6. Recompiler et contrôler les références. **Fait : aucune citation indéfinie, aucune boîte débordante.**

Les réserves sur le revenu de référence, la propagation des droits de porte et les comportements sont des extensions empiriques. Elles ne bloquent pas la diffusion du document de travail.
